# SPARTAKUS — Ecosistema deportivo

Landing page estática para SPARTAKUS: gimnasio, entrenamiento personalizado y eventos deportivos en el corregimiento de Sonso, municipio de Guacarí, Valle del Cauca. Lema: **Tres marcas, una pasión.**

## Probar y desplegar

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático. Para publicar, sube `index.html`, `css/`, `js/` y `assets/` a un hosting estático (por ejemplo, GitHub Pages, Netlify o Vercel). No se requieren dependencias ni compilación.
